# 4단계: CFM + PINN 결합(PG-CFM) — 구현과 약점 분석

기준: 논문 초안 `PINN_FlowMatching_NeurIPS_KO.pdf` 식 (9), (10), (12), (18), 부록 C. 2단계 CFM(`pgcfm/cfm.py`, torchcfm)과 3단계 잔차(`pgcfm/physics/`, Raissi PINNs 포팅 + 격자 차분)를 그대로 쓰고, 그 둘을 잇는 부분만 새로 만들었습니다.

## 구현한 것

| 파일 | 내용 |
| --- | --- |
| `pgcfm/coupling.py` | `PhysicalBridge` h_ψ (식 9, a(1−a) 인자로 양 끝점 정확), `Closure` C_χ(x_k, c_k), `PhysicsGuide`(역정규화 → 3단계 격자 잔차, Simpson 시간적분 식 18), `PGCFM.joint_loss`(식 12), energy score(식 13, 선택), `estimate_scales`(b_j), `deterministic_rollout`(ε=0), `HydrostaticProjection`(실험용) |
| `pgcfm/train.py` | 부록 C 단계 `cfm → guide → joint`, 멀티 GPU gradient 평균, `balanced_backward`(물리 gradient 상한), 1일 검증 |
| `scripts/train_pgcfm.py`, `configs/pgcfm_era5.yaml` | 실제 KAI ERA5 학습 (단일 GPU / `torchrun`, 단계별 체크포인트, `--resume`) |
| `scripts/infer_pgcfm.py` | 멤버별 Markov rollout → KAI `forecast.nc` (+ ε=0 `_det.nc`), 5단계 `evaluate.py` 입력 형식 |
| `scripts/make_balanced_era5.py` | 정역학 + 지균 균형을 만족하는 합성 자료 (아래 설명) |
| `scripts/run_step4_pgcfm.py`, `scripts/run_step4_projection.py` | 이 문서의 실험 |
| `docs/step4/` | 세 실험의 원시 결과(json)와 로그 |
| `tests/test_coupling.py` | 6개: h_ψ=0이면 3단계 선형 bridge와 일치, 끝점 보존, L_phys → θ gradient 도달, 관측 쌍 mask, b_j 하한, 학습·추론 스크립트 end-to-end |

결합의 핵심 경로는 논문 그대로입니다. 학습 중 새 ε로 미분 가능한 Heun 적분(2 step)을 돌려 ŷ를 만들고, B_ψ(s) = (1−a)x + aŷ + a(1−a)h_ψ 위에서 시간적분 잔차를 계산합니다. ŷ를 detach하지 않으므로 L_phys → B_ψ → ŷ → θ로 gradient가 흐릅니다(`test_physics_gradient_reaches_theta`). 유효 collocation mask는 관측 쌍의 지표기압으로 정해서, 생성 멤버가 ps를 낮춰 잔차 계산점을 없앨 수 없습니다.

**논문과 다르게 한 것**: h_ψ를 좌표 MLP가 아니라 격자 CNN으로 만들었습니다. 121×240×12점의 좌표 MLP를 CFM 학습 루프 안에서 매 batch 돌리는 것은 비용상 불가능합니다. 시간적분 잔차(식 18)는 Simpson 노드에서 A_j(B(s))만 필요하고 ∂_s h_ψ는 쓰지 않으므로, 이 형태에서는 잃는 것이 없습니다. 좌표 PINN(`physics/pinn.py`)은 강형 잔차 ablation용으로 남겨 두었습니다.

## 실험 설정

1단계 합성 자료는 원시방정식을 전혀 만족하지 않아서, 그 위에서는 physics guide가 생성기를 자료에서 **멀어지게** 할 수밖에 없습니다. 그래서 `make_balanced_era5.py`로 진실이 제약 집합 근처에 있는 자료를 만들었습니다: AR(1) 온도에서 z를 정역학으로 적분하고, T를 잔차와 같은 d/d ln p로 다시 구하고(진실의 R_hyd = 0), u, v를 지균풍으로 둡니다(적도 ±15°는 f 고정). 시간 진화는 여전히 AR(1)이라 운동량·열역학 방정식은 적분되지 않습니다.

- 격자 25×48, 12층, 66 동적 채널. 학습 4년 × 90일 = 356쌍, 시험 2020년 4개 초기장, 10일 rollout, 멤버 8, Heun 8 step.
- 공통 CFM 1200 iter를 한 번 학습한 뒤 갈래마다 같은 θ 갱신 횟수(300 iter)를 줍니다. CFM 단독은 CFM 손실만 300 iter 더, PG-CFM은 guide 150 iter(θ 고정) + joint 300 iter(λ_P를 100 iter 동안 올림).
- 잔차는 b_j로 나눈 값이고, "독립 잔차"는 선형 bridge + closure 없음으로 계산합니다(h_ψ, C_χ가 줄일 수 없는 값).
- CPU 4코어, 실험 전체 약 40분. 수치는 정규화 단위입니다.

## 약점 분석

### W1. b_j = 관측 잔차 RMS는 퇴화한다 (수정함)
논문 5.1은 b_j를 학습 자료의 잔차 크기로 정합니다. 그런데 자료가 거의 정확히 만족하는 제약은 b_j → 0이 됩니다. mass 잔차는 ω를 연속식으로 진단하므로 **실제 ERA5에서도 정의상 거의 0**이고(3단계 문서), 균형 합성 자료에서는 hyd도 0입니다. 첫 smoke test에서 b_hyd = 2e-4 K가 되어 L_phys ≈ 1.7e9로 폭주했습니다. 지금은 b_j ≥ 0.1 × 기본 종관 규모로 하한을 둡니다(`scale_floor_frac`). **논문 수정 제안**: b_j는 "관측 잔차 RMS"가 아니라 "관측 잔차 RMS와 생성기 오차 규모 중 큰 값"으로 정의하고, mass는 진단 ω를 쓰는 한 독립 제약이 아니라고 명시해야 합니다.

### W2. 물리 gradient가 CFM gradient의 약 3000배라서 λ_P가 의미를 잃는다
joint 단계에서 ‖∇_θ L_phys‖ ≈ 1900, ‖∇_θ L_CFM‖ ≈ 0.63입니다. 전역 gradient clipping(1.0) 뒤에는 갱신 방향이 사실상 L_phys 하나이고, 그래서 λ_P = 0.1과 1의 결과가 소수 셋째 자리까지 같습니다. 이 상태에서 CFM 손실은 1.34 → 1.76(λ_P=1은 1.99)으로 오르고, 1일 CRPS는 26% 나빠지는데 독립 잔차는 u 4%, hyd 20%만 줄어듭니다.

반대로 물리 gradient를 CFM의 0.1배 또는 0.5배로 제한하면(`grad_ratio`) 실효 배율이 3e-5, 2e-4가 되어 결과가 CFM 단독과 같아집니다. **두 극단 사이에 "skill을 지키면서 잔차를 줄이는" 영역을 300 iter 안에서는 찾지 못했습니다.** 손실 가중치(λ_P)가 아니라 gradient 크기의 균형이 실제 조절 변수이고, 논문 6.1의 "가중치를 점진적으로 증가"는 gradient norm 기준으로 다시 써야 합니다.

### W3. PG-CFM의 장기 lead 이득은 물리가 아니라 진폭 축소에서 온다
5일, 10일에서 PG-CFM이 CFM 단독보다 RMSE와 CRPS가 좋습니다(10일 CRPS 0.596 vs 0.634). 그러나 독립 잔차는 거의 그대로이고(10일 hyd 80 vs 91, 진실 0), 멤버 진폭이 1.42 → 1.05로 줄어 진실(1.10–1.21)보다 작아졌습니다. 진폭이 기후값 쪽으로 줄면 긴 lead의 RMSE는 자동으로 좋아집니다. PR #2 교훈(quasi-static으로 수렴하는 모델이 RMSE에서 이기는 문제)과 3단계의 "정지 대기도 잔차가 0인 해" 결과와 같은 방향입니다. **PG-CFM의 이득을 주장하려면 CRPS와 함께 멤버 진폭, 스펙트럼, tendency 진폭 비를 반드시 같이 보고해야 합니다.** 같은 이유로 CFM 단독의 1일 과대분산(SSR 1.25, 진폭 1.42 vs 1.21)도 별도 문제로 남습니다.

### W4. 생성 멤버의 정역학 위반은 채널별 독립 noise에서 온다
CFM 단독 멤버의 hyd 잔차는 76 b(약 7.6 K)인데 진실은 0입니다. 정역학을 penalty 대신 hard constraint로 걸어 보았습니다(T를 생성된 z에서 진단). hyd는 0.03으로 사라졌지만 spread가 2배(1.13 → 2.17), CRPS가 23% 나빠졌습니다. ε=0 경로의 RMSE는 투영 전후가 같으므로(0.932 vs 0.933) 악화는 전부 noise 쪽입니다. 즉 ε가 층마다 독립이라 z의 연직 미분이 noise를 증폭합니다. 이것이 W2에서 L_phys가 그렇게 큰 이유이기도 합니다.

**논문 수정 제안(다음 단계)**:
1. 진단 제약(정역학, 연속)은 penalty가 아니라 출력 parameterization으로 만족시킨다. 방향은 미분(T ← z)이 아니라 적분(z ← ∫T d ln p, 지표 z와 T, q만 생성)이어야 noise가 증폭되지 않는다.
2. base noise ε를 채널·층 사이에 상관된(예: 연직 EOF 공간의) Gaussian으로 바꾼다. 현재 ε ~ N(0, I)는 물리적으로 불가능한 방향으로 분산을 넣는다.
3. L_phys는 예보 방정식(운동량, 열역학, 수분)의 시간적분 잔차에만 남긴다.

### W5. bridge h_ψ가 진실의 정역학 균형을 깬다
guide 단계 후, 관측 쌍을 학습된 bridge + closure로 이으면 운동량·온도 잔차는 1 → 0.6–0.7로 줄지만 **hyd는 0 → 2.5–2.9로 생깁니다.** h_ψ가 경로 중간에서 운동량 잔차를 줄이기 위해 z, T를 비정역학적으로 바꾸는 것입니다. λ_H ‖h‖² 정규화만으로는 이것을 막지 못합니다. h_ψ도 W4의 parameterization(정역학을 만족하는 형태)으로 출력하게 하거나, 경로 노드에서 hyd를 반드시 포함해야 합니다(지금은 포함되어 있지만 b_hyd 하한 때문에 가중이 상대적으로 작습니다).

### W6. 비용
joint 단계는 같은 iter의 CFM 단독보다 7배 느립니다(338 s vs 48 s): 미분 가능한 Heun 2 step(U-Net 순전파 4회 + 역전파)과 float64 잔차 5 노드. 121×240에서는 GPU 메모리가 먼저 한계가 될 수 있어 `batch`, `sample_steps`, `n_sub`를 조절할 수 있게 했습니다. 학습 중 sample_steps=2인 ŷ는 추론(8 step) 분포와 다르다는 점도 남습니다(학습-추론 불일치).

### W7. 이 실험의 한계
- 합성 자료의 시간 진화가 AR(1)이라 운동량·열역학 잔차의 의미가 제한적이고, closure가 무엇을 흡수했는지(식별성)는 검증할 수 없습니다.
- joint 300 iter는 짧습니다. 물리 gradient가 큰 상태로 오래 학습하면 W3의 진폭 축소가 더 진행될지, 균형이 학습될지는 실제 GPU 학습에서 봐야 합니다.
- 격자 25×48에서는 극 필터와 1/cos φ 문제(3단계 W)가 실제 121×240보다 약합니다.
