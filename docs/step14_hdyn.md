# 14단계: 신경연산자를 둘 자리 네 곳 (소유자 결론3, H-dyn 가설)

## 요청을 이렇게 읽었습니다

소유자 결론3(2026-10-26 11:45)은 13단계 결과를 "연산자가 이긴 자리는 함수 → 함수 비선형 사상 + 연산자 노름의 명시적 제어가 필요한 자리뿐"이라고 읽고, 네 자리를 시험하자고 했습니다. 이어서(11:52, "이거 반영") 주 가설과 보조 가설 셋을 기각 기준과 함께 정했습니다.

| 가설 | 명제 | 통과 | 기각 |
| --- | --- | --- | --- |
| **H-dyn** (주) | 흐름 의존 퍼짐은 조건부 분산 추정이 아니라 학습된 벡터장의 접선 선형 Φ_t가 rollout 동안 만든다. 노름 투영 FNO는 Grönwall 상한으로 성장률을 선험적으로 제어한다 | 잡음 제거 사례 간 퍼짐 변동 ≥ 8 %, 영역 퍼짐 CV ≥ 0.06, 퍼짐 5분위 오차 비 ≥ 1.2, 144 h SSR 0.9–1.2 (Γ 없이), 투영이 실제로 걸리고 빼면 나빠짐 | 5 % 미만, 0.05 그대로, 1.1 미만, B를 낮춰도 발산, 빼도 같음 |
| **H-cl** | 예후 → 진단 변수 사상은 연산자가 MBM을 이긴다 | u10/v10 이득이 t2m·tcwv로 ≥ 5 % 이전 | 2 % 미만이면 바람에만 한정 |
| **H-bal** | 전 모드 노름 투영 FNO 사영 Π_θ는 PINN(8×16 모드)이 못 고친 지균 잔차를 줄이면서 접선 분산을 유지한다 | 지균 잔차 감소, 퍼짐 비 ≥ 0.95, q·tcwv 음수 → 0 (질량 보존) | 감소가 정역학에 머묾, 퍼짐 비 < 0.9 |
| **H-res** | 32×64에서 학습한 연산자는 64×128에 제로샷 전이된다 | 64×128 이득이 32×64 이득의 ≥ 70 % | 이득이 사라지거나 역전 |

비교 기준선은 13단계 최고 모델 regm_sband_clim_flow(−1.17 %)로 고정하고, H-dyn은 CRPS가 아니라 흐름 의존 지표로 판정합니다.

CPU에서 이렇게 줄였습니다.

- **H-dyn**: 경로 2(물리 시간 rollout)는 12단계의 결정론 코어(`pgcfm/core.py` jump6, 실제 ERA5 5변수, 6 h 연쇄 24회 = 144 h)가 이미 돌아가므로, 그 경향망 D를 노름 투영 FNO로 바꿉니다. 멤버는 같은 분석장에 등방 섭동(모든 사례에 같은 통계)을 더해 rollout합니다. 사례 간 퍼짐 차이는 Φ_t만 만들 수 있습니다.
- **H-cl**: 13단계 회귀 앙상블 위의 μ* = a + b·μ + c·x(t)에서 출발해 진단 변수(t2m, u10, v10)만 고치는 연산자. tcwv는 5변수 자료에 없습니다.
- **H-bal**: 13단계 1단계 PINN 시험(`scripts/run_step13_pinn.py`)에 Π_θ를 같은 관문(항등, 물리, 수축)으로 넣고 지균 잔차와 양수·질량 지표를 더했습니다.
- **H-res**: FM 생성기는 32×64만 만들므로, H-dyn의 결정론 코어를 WeatherBench2의 64×128 ERA5에 제로샷으로 돌립니다.

읽은 것:

1. **소유자 기준으로 H-cl은 기각입니다.** 진단 연산자의 t2m 이득은 μ* 대비 1.5 %로 기각선 2 % 아래이고, 바람(5~6 %)에만 머뭅니다.
2. **같은 자리에서 CNN이 연산자를 이깁니다.** u10 24 h −14 % 대 −5 %, t2m −3.4 % 대 −1.5 %. 진단 관계가 지형·해륙 같은 국소 정적장에 크게 의존한다는 뜻으로 읽고 있지만, 검증한 것은 아닙니다(추정). CNN의 매개변수가 더 많은 점(29만 대 19만)도 단서입니다. 어느 쪽이든 "연산자의 본령"이라는 결론3의 읽기는 이 자리에서는 지지되지 않습니다.
3. **노름 투영은 연산자를 낫게 합니다.** 제약 없는 연산자는 검증 손실이 2 epoch에서 최소(0.1929)이고 B ≤ 1은 8 epoch(0.1886), 시험에서도 모든 진단 변수가 B ≤ 1이 낫습니다. 13단계 4.4의 결과(839 → 821)와 같은 방향입니다.
4. **새로 나온 것: 다섯 변수 전부를 고치는 노름 투영 연산자가 예후 변수를 고칩니다.** z500 144 h 778 → 756, t850 3.45 → 3.19(−7.5 %). 13단계에서 제약 없는 연산자가 MBM에 졌던 것과 다르고, 차이는 (가) μ* 위의 0 초기화 잔차와 (나) 노름 투영 둘입니다. 다만 z500 24 h는 244 → 250으로 나빠졌고, 한 번 학습(seed 하나)입니다.

fair CRPS 미세조정: 학습된 코어에서 출발해 같은 등방 섭동 멤버 4개의 rollout(창 8 = 48 h, 배치 2, 600 iteration, lr 2e-4)을 fair CRPS로 학습(`scripts/run_step12_core.py --crps-members 4 --init`). 학습 창이 4 → 8로 길어진 것도 같이 바뀌어서, 결정론 성능의 개선(ResNet z500 144 h 1065 → 924)은 둘 중 무엇 때문인지 가르지 못했습니다.

영역 퍼짐과 오차의 사례 간 상관(z500 144 h): 기준선 0.41, ResNet + fair CRPS 0.10, FNO B = 2 + fair CRPS **−0.28**.

**선험 상한은 비어 있습니다.** 한 단계 x → x + s6·D에서 상태 섭동만 따져도 Lip ≤ 1 + max(s6)·Lip(D) = 1 + 0.42·Lip(D)이고, B = 1에서도 1.98, 24단계면 10⁷입니다. 실제 144 h 퍼짐 성장은 0.8–3.2배였습니다. 선험 상한이 의미 있는 크기가 되려면 Lip(D)가 0.15 아래여야 하는데, B = 1(Lip 2.3)에서 이미 코어가 지속성 수준(z500 24 h 539 대 572)으로 굳었습니다.

읽은 것 (소유자 기준 표 순서):

1. **격자점 퍼짐의 사례 간 변동 (≥ 8 %): 통과, 단 노름 상한이 느슨할 때만.** rollout은 FM이 못 만든 것을 만듭니다. ResNet 0.21, fair CRPS를 더하면 0.24로 144 h에서 기준선(0.14)보다 큽니다. 반대로 상한을 조이면 사라집니다: FNO 0.11(제약 없음) → 0.11(B = 4) → 0.06(B = 2) → 0.02(B = 1). FM + Γ(regm_band)는 0.02–0.04로 변동이 없는 대조군(0.02)과 같습니다. 즉 13단계 진단("한 번에 생성하는 CFM에는 Φ_t가 없다")은 맞습니다.
2. **영역 퍼짐 CV (≥ 0.06): FNO B = 2 + fair CRPS만 통과(0.112), 그러나 오차와 반대로 움직입니다(상관 −0.28).** 퍼짐이 큰 사례가 오차가 작은 사례라는 뜻이라 흐름 의존이 아니라 일부 사례에서 커지는 불안정으로 읽습니다. 나머지는 0.04–0.06입니다.
3. **퍼짐 5분위 오차 비 (≥ 1.2): 모두 기각 쪽.** 가장 높은 것이 ResNet + fair CRPS 1.15–1.16(z500), 1.13–1.18(t850)이고, FNO는 전부 1.01–1.04로 기각선(1.1) 아래입니다. 기준선의 σ장(NLL로 학습)은 1.20–1.29, t850 1.41–1.46으로 여전히 가장 높습니다.
4. **SSR 0.9–1.2 (Γ 없이): 기각.** 0.13–0.41입니다. 섭동 크기는 상수 하나라 바꿀 수 있지만, 24 → 144 h 퍼짐 성장(×0.9–2.2)이 오차 성장(×1.9–3.4)보다 느려서 두 lead를 동시에 맞출 수 없습니다(B = 2 + fair CRPS만 반대로 퍼짐 ×3.3, 오차 ×2.2).
5. **노름 투영 (실제로 걸리고, 빼면 나빠짐): 기각.** B = 1에서는 30 %의 노름을 실제로 잘랐지만 성능과 흐름 의존이 같이 무너졌고, B = 4는 학습 끝에 한 번도 걸리지 않아 제약 없음과 같습니다. B = 2만 z500 144 h를 1048 → 1017로 낫게 했고(24 h는 440 → 482로 나빠짐), 흐름 의존은 줄였습니다. 예측과 반대 방향: 상한이 흐름 의존을 만드는 것이 아니라 깎습니다.

정리: H-dyn의 앞부분("흐름 의존은 rollout의 Φ_t가 만든다")은 격자점 수준에서 지지되고, 뒷부분("노름 상한 FNO가 그것을 제어해 낸다")은 이 CPU 규모에서 기각입니다. 다만 FNO 코어 자체가 약합니다(24 h 오차가 ResNet보다 40 % 큼, 1500 iteration). GPU에서 FNO를 충분히 학습하면 결론 5가 바뀔 여지는 남습니다.

## 4. H-res: 32×64 코어를 64×128에 제로샷으로 (결과)

같은 가중치와 같은 정규화(5.625° 2006–2015 통계)로, 64×128의 초기장·정적장·시간 특징을 넣어 직접 돌린 것(native), 32×64에서 돌린 결과를 경도 주기 쌍선형으로 올린 것(interp), 각 해상도의 지속성. 점수는 각 해상도의 ERA5 truth 대비. skill = 1 − RMSE / RMSE(지속성, 같은 해상도).

2. **그러나 64×128에서 가장 좋은 예보는 "32×64에서 돌리고 올린 것"입니다.** z500과 t850의 RMSE는 interp가 native보다 낮습니다(모든 코어). 해상도가 올라가도 코어가 새 작은 규모를 예측하지 못하므로, 매끈한 보간이 RMSE에서 이깁니다. 예외는 t2m 24 h로, native가 지형·해륙 정적장을 고해상도로 받아 interp보다 낫습니다(FNO 1.86 대 2.09).
3. 소유자 기준은 "보정 연산자의 CRPS 이득"이었는데, FM 생성기가 32×64만 만들어서 결정론 코어로 바꿔 쟀습니다. H-cl의 다섯 변수 연산자(B ≤ 1)도 FNO라 같은 성질을 가질 것으로 보지만 재지 않았습니다.

## 5. H-bal: 전 모드 노름 투영 FNO 사영 (결과)

13단계 1단계 PINN 시험과 같은 관문입니다. 2016년의 ERA5 6 h 연쇄 32개(K = 24)에 FM 멤버를 흉내 낸 섭동 d~ = d + α·ε(ε는 리드·DCT 계수별 d의 표준편차를 가진 가우스)를 더하고, 사영 뒤의 잔차를 ERA5 자신의 잔차로 나눕니다. 학습도 같습니다: 1000 iteration, 배치 4, 손실 = 입력과의 거리 + 0.05 × 물리 잔차(+ λ_geo × 비지균풍²). Π는 매개변수 866만(PINN 143만), 학습 58분입니다.

질량 층을 한 번 고쳤습니다. 첫 판(λ_geo 1)에서 N의 보정이 전구 수분을 1.2 % 옮겼고, pos 층이 N 뒤의 질량을 지켰기 때문에 그대로 남았습니다. pos 층이 입력 프레임의 질량으로 재척도하게 바꾸었고(`PositiveMass(x, ref)`), 그 판은 같은 가중치로 관문만 다시 쟀으며 λ_geo 0 판은 고친 층으로 학습했습니다. 질량 변화는 5 × 10⁻⁸(부동소수 반올림)입니다.

α = 0.5에서 사영 전 → 후 (ERA5 = 1). 마지막 열은 ERA5 자신(α = 0)에 Π를 적용한 것입니다.

읽은 것 (소유자 기준 순서):

1. **지균 잔차 감소: 기각.** B = 0.8은 α = 0.5에서 2.47 → 2.44로, ERA5보다 많은 몫(1.47) 가운데 2 %만 없앴고, 지균 손실을 빼도(λ_geo 0) 같은 2.44입니다. 상한을 풀수록 더 내려가지만(B = 1.4 2.37, 상한 없음 2.16), 위 분해로 보면 이 몫은 전부 ERA5 자신의 평균 보정과 퍼짐 축소로 설명됩니다(2.37 / 2.36, 2.16 / 2.16). 어느 판도 섭동의 비지균 성분을 되돌리지 않았습니다.
2. **"감소가 정역학에 머묾"이 상한을 없앤 판에서 그대로 나옵니다.** 진짜 사영이 일어난 곳은 정역학(1.95 대 2.60), 질량 연속(1.34 대 1.61), v 운동량(1.89 대 2.03)이고 지균은 아닙니다. PINN도 정역학만 고칩니다(2.40 대 2.86). B = 1.4는 T(1.70 대 1.79)와 q(1.46 대 1.58)에서만 사영하고, B = 0.8은 q의 작은 몫(clamp 효과일 수 있음) 말고는 어디서도 사영하지 않습니다. 어떤 제약을 사영하는지가 상한마다 바뀌는 것은 판마다 seed 하나라서 학습 편차일 수 있습니다.
3. **퍼짐 비 ≥ 0.95: B = 0.8과 1.4는 통과(0.963–0.996), 상한 없음은 기각선(0.9)에 걸립니다(0.888–0.906).** 소유자가 예측한 "‖Π‖ ≤ 1이면 퍼짐을 지키면서 균형을 고친다"는 둘이 함께 나오지 않았습니다. 상한이 조이면 퍼짐은 지키지만 아무것도 고치지 않고, 풀면 고치지만 퍼짐을 10 % 줄입니다. 중간 B = 1.4(선험 Lip(Π) ≤ 9.8)는 퍼짐 0.963–0.991로 통과하고 T·q는 사영하지만, 지균·정역학은 고치지 않습니다.
4. **음수 → 0, 질량 보존: 모든 Π에서 통과. 단 이것은 FNO가 아니라 clamp + 재척도 층이 한 일입니다.** 같은 층을 PINN 뒤에 붙여도 같은 결과가 나옵니다. PINN만으로는 음수 비율이 그대로이고, 클램프하면 전구 수분이 0.8–3 % 늘어납니다.
5. **노름 상한이 걸린 Π는 사영이 아니라 평균 보정을 배웠습니다.** ERA5 자신(α = 0)에서 잔차를 6–15 % 줄이고(지균 0.938, v 0.854, T 0.860), 섭동이 커질수록 상대 감소가 줄어듭니다(지균 0.94 → 0.97 → 0.99 → 0.996, 그림 위 왼쪽). 즉 "ERA5가 이산 방정식과 어긋나는 몫"(한 단계 경향의 12 % 크기)을 상태와 거의 무관하게 고칩니다. 6단계에서 사영이 평균 보정을 배운 것과 같은 실패입니다. 상한을 없앤 판도 ERA5에서 더 크게 고치고(변화량 0.21 × 6 h 경향, 지균 0.765), 그 위에 정역학·질량 사영을 더합니다.
6. **노름 투영은 실제로 걸리고, 빼면 결과가 바뀝니다. 그러나 방향이 예측과 반대입니다.** 상한은 사영을 가능하게 하는 것이 아니라 막습니다. B = 0.8에서 블록마다 이득이 1.129 × 0.8 = 0.9로 1보다 작아서, 네 블록을 지나면 섭동 방향의 보정이 줄어든다고 읽고 있습니다(추정). 같은 손실(λ_geo 1)에서 학습 끝 물리 손실은 B = 0.8 49, B = 1.4 46, 상한 없음 33이고, 입력과의 거리는 0.04, 0.07, 0.19입니다. 상한을 풀수록 많이 움직이고 물리 손실이 내려갑니다.

왜 지균을 못 고치는지(추정, 검증 안 함): 지균풍 u_g = −Φ_φ / (f a)는 위도에 따라 계수가 바뀌는 사상인데, FNO의 스펙트럴 층은 (두 배로 늘린 구에서) 위도 방향 평행이동에 대해 등변이라 1/f를 곱하는 일을 정적장 채널(sin φ)과 GELU의 곱으로 근사해야 합니다. 섭동 ε는 채널끼리 독립이라 비지균 성분이 모든 규모에 퍼져 있어서, 이것을 되돌리려면 이 위도 의존 사상을 정확히 표현해야 합니다.

## 6. 종합

| 가설 | 판정 | 근거 |
| --- | --- | --- |
| H-dyn (주) | 앞부분 지지, 뒷부분 기각 | rollout은 격자점 퍼짐의 사례 간 변동을 만든다(ResNet 0.21, fair CRPS 0.24 > 기준선 0.14). 노름 상한은 그것을 깎는다(B = 1에서 0.02). 오차 비 최고 1.16 < 1.2, SSR 0.13–0.41, 선험 상한 10⁷ |
| H-cl | 기각 | t2m 이전 1.5 % < 2 %. 같은 자리에서 CNN이 연산자를 이긴다. 다섯 변수 B ≤ 1 연산자는 z500 144 h 778 → 756 |
| H-bal | 지균 기각, 퍼짐과 균형 사영은 함께 나오지 않음 | 어느 상한에서도 지균 감소는 평균 보정 + 퍼짐 축소뿐. B = 0.8: 퍼짐 통과, 사영 없음. B = 1.4: 퍼짐 통과, T·q만 사영. 상한 없음: 정역학·질량·v 사영, 퍼짐 0.90(기각선). 음수·질량은 clamp 층이 해결 |
| H-res | FNO 통과, ResNet 기각 | FNO는 64×128에서 skill 85–102 % 유지, ResNet 19–39 %. RMSE는 32×64에서 돌리고 보간한 것이 더 낮다 |

약점 (이 결과를 읽을 때):

- 모두 CPU 규모입니다. FNO 코어는 1500 iteration으로 24 h 오차가 ResNet보다 40 % 크고, Π는 1000 iteration입니다. seed 하나씩입니다.
- H-dyn의 멤버는 등방 IC 섭동만 씁니다. 모델 오차 섭동이 없으므로 SSR이 낮은 것은 일부 설계 때문입니다.
- fair CRPS 미세조정은 학습 창(4 → 8)도 같이 바꿔서 두 효과를 가르지 못했습니다.
- H-res는 소유자 기준(보정 연산자의 CRPS 이득) 대신 결정론 코어의 RMSE skill로 쟀습니다.
- H-bal의 섭동은 채널끼리 독립인 가우스라 실제 FM 멤버의 비지균 성분보다 클 수 있습니다. B = 0.8, λ_geo 1 판은 고치기 전 질량 층으로 학습했습니다. Π는 상한마다 학습 한 번이라, 어느 제약을 사영하는지(B = 1.4는 T·q, 상한 없음은 정역학·질량)가 상한 때문인지 seed 때문인지 가르지 못했습니다.
- H-bal은 관문(2016 검증)까지만 쟀고, Π를 FM 멤버에 붙여 2017–18 예보 점수를 내지는 않았습니다.
- 선험 Lipschitz 상한(곱 형태)은 모든 판에서 비어 있습니다. 노름 투영이 실제로 잘랐는지는 기록했지만, 실제 접선 성장률은 rollout 퍼짐으로만 쟀습니다.
