# 24단계: 자료 효율 곡선 (학습 1년, 2년, 4년, 37년)

소유자 질문(2026-10-28 07:25): "대형 모델과의 비교에서 우리 모델의 우수성을 드러낼 수 있는 실험은?" 네 축 가운데 자료·연산 효율 축입니다.
13단계 보고 모델 regm_band(회귀 평균 + FM 편차 + 닫힌 형 대역 Γ)를 학습 연도만 바꿔 CPU에서 다시 학습하고, ClimODE의 360개 시험 IC(2017~18)에서 채점했습니다.

**결론: 6일(144 h)에서는 4년 학습이 37년 학습 성능의 대부분을 냅니다(778 대 741, 5 % 차이). 24 h에서는 그렇지 않습니다(244 대 170, 43 % 차이).**
37년 점은 반복 수가 53배인 GPU 실행이라, 24 h의 큰 차이에는 자료와 연산이 섞여 있습니다. 보정(대역 Γ)은 학습 연도와 상관없이 같은 수준(spread-skill 1.13~1.21)을 유지합니다.

## 1. 방법

- `runs/step24/queue_years.sh`가 `scripts/run_step13_best.sh`를 `TRAIN_YEARS="2015"`(1년)와 `"2014 2015"`(2년)로 돌립니다. PINN, FM, 회귀, regm_band 보정, 채점까지 13단계와 같은 명령이고
  `SIGMA=0 SBAND=0 BLEND=0`입니다. 보정 해는 늘 2016, 시험은 2017~18의 360 IC입니다.
- 반복 수는 small 프로필 그대로입니다: PINN 1000회(배치 4), FM과 회귀 각 3000회(배치 4). 그래서 모든 CPU 실행이 같은 12,000개 표본을 봅니다(1년은 표본마다 약 8번, 4년은 약 2번).
- 4년 = 13단계 실행(`runs/step13/score_regm.json`, 학습 2012~2015). 37년 = 소유자의 GPU 실행(커밋 2dd09f2, `docs/step13_broad/step13_broad_report.pdf`, 학습 1979~2015,
  FM과 회귀 각 40000회 배치 16). 37년 실행의 json은 저장소에 없어 보고서 4절 표의 숫자(z500 RMSE 170 / 423 / 741, t850 1.49 / 2.22 / 3.21 K, z500 CRPS 0.0076 / 0.0183 / 0.0310, spread-skill 1.22 / 1.16 / 1.10)만 씁니다.
- 그림 `docs/step24/fig_data_efficiency.png`(`scripts/plot_step24_years.py`), 수치 `docs/step24/data_efficiency.json`.

- **자료가 적을수록 보정의 몫이 큽니다.** regm_band의 5변수 CRPS는 같은 실행의 회귀 앙상블보다 1년 −7.7 %, 2년 −5.7 %, 4년 −4.5 % 낮습니다.
- 1년 학습도 144 h에서 ClimODE 논문(784)과 60 이내(843), 2년은 22 이내(806)이고, 4년부터 아래(778)입니다. 4년 blend_band(20단계)는 723입니다.

## 3. 판정 (가설 문서 H9)

H9 "4년 학습으로 37년 학습 성능의 대부분을 얻는다"는 **부분 지지**입니다. 144 h에서는 지지(5 % 차이, 개선 몫 64 %), 24 h에서는 기각(43 % 차이, 개선 몫 32 %)입니다.
논문 문장으로는 "중기(6일) 오차와 보정은 수 년의 자료로 포화에 가깝고, 단기 오차는 자료와 연산을 늘리면 계속 준다"가 맞습니다.
"작은 자료로 대형 모델에 맞먹는다"는 주장은 하지 않습니다.

## 4. 약점

1. **자료와 반복이 섞여 있습니다.** CPU 실행은 모두 12,000개 표본(3000회 × 배치 4)이라 1년은 같은 표본을 8번, 4년은 2번 봅니다. 37년 GPU 실행은 표본 수가 53배(40000회 × 배치 16)입니다.
   그래서 4→37년의 24 h 이득 −30 %가 자료 때문인지 반복 때문인지 나눌 수 없습니다. 나누려면 GPU에서 같은 반복으로 4년, 10년(`PROFILE=climode`), 37년을 돌려야 합니다.
2. **37년 점은 보고서 숫자 세 lead뿐**이고 그 실행의 json이 저장소에 없습니다. 소유자께서 기억하신 24 h 177이 다른 GPU 실행이라면 그 json으로 바꿔야 합니다(보고서 2dd09f2의 표는 170).
3. **학습 연도 선택이 하나이고 시드도 하나입니다.** 1년 = 2015, 2년 = 2014~15로 보정 해 2016에 가장 가까운 해만 썼습니다. 연도 간 변동은 재지 않았습니다.
4. **best 모델이 아니라 13단계 모델입니다.** blend_band는 G(x) 코어 학습(약 2시간)이 더 필요해 1·2년에는 돌리지 않았습니다. 혼합의 이득이 자료 양에 따라 어떻게 바뀌는지는 모릅니다.
5. **보정 해는 늘 1년(2016)입니다.** 보정 자료의 양은 바꾸지 않았습니다.
