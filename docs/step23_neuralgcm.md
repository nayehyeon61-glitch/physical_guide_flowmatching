# 23단계: NeuralGCM 공개 체크포인트와의 비교 (시험 해 2020)

소유자 요청(2026-10-28 05:58): "NeuralGCM과도 비교 가능할까요? 공개 체크포인트로 가능할까요?" → 선택: CPU에서 2.8° 결정론 체크포인트만 지금.
소유자의 전제(06:06): 비교가 우리에게 불리합니다. NeuralGCM은 엄청난 고해상도·장기간 자료로 학습했고 우리는 자료를 줄여 썼습니다. 그래서 이 문서는
NeuralGCM을 "이긴다"가 아니라 **GCM급 하이브리드의 상한 참조**로 두고, 조건의 비대칭을 표로 같이 적습니다.

## 1. 왜 2020년인가, 무엇을 다시 학습하지 않는가

- NeuralGCM(Kochkov et al. 2024, Nature)의 공개 체크포인트(`gs://neuralgcm/models/v1/`, CC BY-SA 4.0)는 2.8°·1.4° 결정론이 ERA5 1979~2017로, 0.7°와 1.4° 확률론이 1979~2019로 학습되었고
  논문의 시험 해는 2020입니다. 우리 ClimODE 규약의 시험 해 2017~18은 NeuralGCM의 학습 자료라 그대로 쓸 수 없습니다.
- 아무것도 다시 학습하지 않습니다. NeuralGCM은 체크포인트를 그대로 추론만 하고, 우리는 13·16단계 가중치(FM, 회귀, PINN, G(x) 코어)와 2016년 보정 상수(대역 Γ, MBM, 혼합 계수)를
  고정한 채 **2020년 멤버만 새로** 만듭니다(`runs/step23/queue_2020.sh`). 13단계 보고 모델 regm_band와 20단계 best 모델 blend_band 둘 다.
- 비교 변수는 두 모델이 공유하는 **z500·t850**뿐입니다. NeuralGCM은 기압면 u·v·T·q·z만 내고 t2m·u10·v10이 없습니다.

## 2. 조건의 비대칭

| | NeuralGCM 2.8° 결정론 (체크포인트) | 우리 blend_band (CPU) |
| --- | --- | --- |
| 학습 자료 | ERA5 0.25°, 37 기압면, 1979~2017 (39년) | ERA5 5.625° (WB2 보존 재격자), 12층 66채널, 2012~2015 (4년) |
| 모델 격자 | TL63 가우스 128×64 (2.8°), 시그마 32층, 역학 코어 + 학습 물리 | 64×32 (5.625°), 시퀀스 FM + 회귀 + G(x) 코어, 6 h 증분 |
| 시간 간격 | 1 h (역학 코어), 학습 시 rollout 최대 수 일 | 6 h, rollout 24 단계 |
| 학습 자원 | TPU (논문: 수 일 규모) | CPU 4코어 (단계마다 수 시간) |
| 입력 | 0.25° ERA5 7변수 × 37층 + SST·해빙 강제 | 5.625° ERA5 66채널 + 지형·시각 |
| 불확실성 | 없음 (결정론; 확률론은 1.4°만, GPU 필요) | 8멤버 FM 편차 + 대역 Γ |
| 평가 | 출력을 우리 5.625° 격자로 보존 재격자, 같은 IC, 같은 점수 함수 | 저장된 앙상블, 같은 IC |

## 3. 방법

- `scripts/run_neuralgcm_eval.py`: IC마다 ARCO ERA5(0.25°, 37층, 1 h)에서 입력 7변수와 강제(SST·해빙, 저자 데모처럼 24 h 전 값)를 읽어 모델 격자로 보존 재격자(dinosaur),
  encode → 24 h 간격 6일 unroll(강제 고정) → 기압면 복원 → z500·t850을 우리 64×32 격자로 보존 재격자. 결과는 `run_climode_eval.py`와 같은 npz라
  `compare_step13_climode.py --ref-name`으로 같은 IC의 우리 팔을 짝 채점합니다.
- IC: ClimODE 규약(2020년 6 h 지수 2 + 8e, 12 UTC 격일) 중 `--ic-offset 10 --ic-stride 20`(또는 더 촘촘히)로 계절이 고르게 든 부분집합. CPU라 IC당 시간을 재고 수를 정했습니다.
- 우리 팔: blend_band(best), regm_band(13단계 보고 모델), 회귀 앙상블, G(x) 코어 단독(결정론끼리 비교용). 지속성은 기준선.
