# 23단계: NeuralGCM 공개 체크포인트와의 비교 (시험 해 2020)

소유자 요청(2026-10-28 05:58): "NeuralGCM과도 비교 가능할까요? 공개 체크포인트로 가능할까요?" → 선택: CPU에서 2.8° 결정론 체크포인트만 지금.
소유자의 전제(06:06): 비교가 우리에게 불리합니다. NeuralGCM은 엄청난 고해상도·장기간 자료로 학습했고 우리는 자료를 줄여 썼습니다. 그래서 이 문서는
NeuralGCM을 "이긴다"가 아니라 **GCM급 하이브리드의 상한 참조**로 두고, 조건의 비대칭을 표로 같이 적습니다.

## 1. 왜 2020년인가, 무엇을 다시 학습하지 않는가

- NeuralGCM(Kochkov et al. 2024, Nature)의 공개 체크포인트(`gs://neuralgcm/models/v1/`, CC BY-SA 4.0)는 2.8°·1.4° 결정론이 ERA5 1979~2017로, 0.7°와 1.4° 확률론이 1979~2019로 학습되었고
  논문의 시험 해는 2020입니다. 우리 ClimODE 규약의 시험 해 2017~18은 NeuralGCM의 학습 자료라 그대로 쓸 수 없습니다.
- 아무것도 다시 학습하지 않습니다. NeuralGCM은 체크포인트를 그대로 추론만 하고, 우리는 13·16단계 가중치(FM, 회귀, PINN, G(x) 코어)와 2016년 보정 상수(대역 Γ, MBM, 혼합 계수)를
  고정한 채 **2020년 멤버만 새로** 만듭니다(`runs/step23/queue_2020.sh`). 13단계 보고 모델 regm_band와 20단계 best 모델 blend_band 둘 다.
- 비교 변수는 두 모델이 공유하는 **z500·t850**뿐입니다. NeuralGCM은 기압면 u·v·T·q·z만 내고 t2m·u10·v10이 없습니다.

## 2. 조건의 비대칭

| | NeuralGCM 2.8° 결정론 (체크포인트) | 우리 blend_band (CPU) |
| --- | --- | --- |
| 학습 자료 | ERA5 0.25°, 37 기압면, 1979~2017 (39년) | ERA5 5.625° (WB2 보존 재격자), 12층 66채널, 2012~2015 (4년) |
| 모델 격자 | TL63 가우스 128×64 (2.8°), 시그마 32층, 역학 코어 + 학습 물리 | 64×32 (5.625°), 시퀀스 FM + 회귀 + G(x) 코어, 6 h 증분 |
| 시간 간격 | 1 h (역학 코어), 학습 시 rollout 최대 수 일 | 6 h, rollout 24 단계 |
| 학습 자원 | TPU (논문: 수 일 규모) | CPU 4코어 (단계마다 수 시간) |
| 입력 | 0.25° ERA5 7변수 × 37층 + SST·해빙 강제 | 5.625° ERA5 66채널 + 지형·시각 |
| 불확실성 | 없음 (결정론; 확률론은 1.4°만, GPU 필요) | 8멤버 FM 편차 + 대역 Γ |
| 평가 | 출력을 우리 5.625° 격자로 보존 재격자, 같은 IC, 같은 점수 함수 | 저장된 앙상블, 같은 IC |

## 3. 방법

- `scripts/run_neuralgcm_eval.py`: IC마다 ARCO ERA5(0.25°, 37층, 1 h)에서 입력 7변수와 강제(SST·해빙, 저자 데모처럼 24 h 전 값)를 읽어 모델 격자로 보존 재격자(dinosaur),
  encode → 24 h 간격 6일 unroll(강제 고정) → 기압면 복원 → z500·t850을 우리 64×32 격자로 보존 재격자. 결과는 `run_climode_eval.py`와 같은 npz라
  `compare_step13_climode.py --ref-name`으로 같은 IC의 우리 팔을 짝 채점합니다.
- IC: ClimODE 규약(2020년 6 h 지수 2 + 8e, 12 UTC 격일) 중 `--ic-offset 5 --ic-stride 10`, 곧 e = 5, 15, …, 175의 18개(1월 11일부터 20일 간격, 12월 16일까지).
  NeuralGCM은 이 CPU 4코어에서 IC 하나에 약 15분(읽기 14 s, encode와 1 h 간격 144 단계 unroll)이라 18개로 정했습니다.
- 우리 팔: blend_band(best), regm_band(13단계 보고 모델), 회귀 앙상블, G(x) 코어 단독(결정론끼리 비교용). 지속성은 기준선.

### 4.1 결정론 점수: NeuralGCM이 모든 lead에서 훨씬 낫습니다

18개 IC, 2020, 우리 5.625° 격자에서 위도 가중:

| | z500 RMSE 24 / 72 / 144 h | t850 RMSE 24 / 72 / 144 h | z500 ACC 24 / 72 / 144 h |
| --- | --- | --- | --- |
| NeuralGCM 2.8° 결정론 | 47 / 141 / 414 | 0.50 / 0.88 / 1.90 | 0.999 / 0.990 / 0.913 |
| blend_band (best, 앙상블 평균) | 197 / 457 / 721 | 1.59 / 2.50 / 3.26 | 0.981 / 0.886 / 0.699 |
| regm_band (13단계 보고 모델) | 253 / 537 / 788 | 1.79 / 2.74 / 3.45 | 0.969 / 0.841 / 0.643 |
| 회귀 앙상블 | 253 / 541 / 820 | 1.83 / 2.80 / 3.61 | 0.969 / 0.840 / 0.633 |
| G(x) 코어 단독 (결정론) | 206 / 490 / 872 | 1.62 / 2.69 / 4.19 | 0.979 / 0.874 / 0.626 |
| 지속성 | 582 / 925 / 1049 | 2.70 / 4.02 / 4.26 | 0.840 / 0.589 / 0.472 |

- 짝 차이 blend_band − NeuralGCM(z500 RMSE)은 +150 [144, 157] / +316 [299, 334] / +306 [264, 350]로 모든 lead에서 유의하게 NeuralGCM이 낫습니다.
  t850도 +1.09 / +1.62 / +1.36 K로 같습니다.
- 비율 blend_band / NeuralGCM은 z500 RMSE 4.2, 4.0, 3.2, 2.6, 2.1, 1.7(24~144 h), t850 3.2 → 1.7, 앙상블 CRPS 대 NeuralGCM의 결정론 CRPS(=MAE) 3.4 → 1.4입니다.
  **비율이 줄어드는 것은 우리가 따라잡는다는 뜻이 아닙니다.** 절대 차이는 72 h부터 약 300 m²/s²로 그대로이고, 비율이 주는 것은 NeuralGCM의 오차도 자라기 때문입니다.
  추세를 6일 너머로 늘여 읽으면 안 됩니다.
- **우리 숫자는 2017~18과 같습니다.** 가중치를 고정한 blend_band가 2020년 18개 IC에서 197 / 457 / 721, ClimODE 34개 IC(2017~18)에서 193 / 459 / 722입니다.
  학습(2012~2015) 뒤 5년째 해에서도 성능이 그대로이고, 팔의 순위(blend_band < regm_band < 회귀, G(x) 코어는 96 h부터 혼합에 짐)도 같습니다.
- 24 h에서 이미 4배 차이가 납니다. 4.4의 같은 정보 실험에서 이 24 h 차이의 약 80 %는 0.25°·37층 초기장의 정보였고, 72 h부터는 절반쯤이 모델 자체의 차이입니다.

### 4.2 확률 점수: NeuralGCM의 0/1 예보가 우리 확률 예보보다 Brier 점수가 낫습니다

z500 월별 삼분위 사건(문턱은 2006~2015 ERA5), 결정론 NeuralGCM은 사건 확률을 0 또는 1로 둔 예보로 채점했습니다(`step22_prob_quality.py`에 이번에 추가).

| z500 24 / 72 / 144 h | 상위 삼분위 BSS | 하위 삼분위 BSS | spread-skill |
| --- | --- | --- | --- |
| NeuralGCM 2.8° (0/1 예보) | +0.89 / +0.79 / +0.53 | +0.89 / +0.75 / +0.42 | 산포 없음 |
| blend_band | +0.67 / +0.40 / +0.18 | +0.64 / +0.24 / −0.11 | 1.20 / 1.15 / 1.13 |
| regm_band | +0.58 / +0.32 / +0.11 | +0.52 / +0.13 / −0.19 | 1.10 / 1.08 / 1.07 |

- Brier 짝 차이 blend_band − NeuralGCM(상위 삼분위)은 +0.059 [0.055, 0.064] / +0.107 / +0.097로 모든 lead에서 NeuralGCM이 유의하게 낫습니다. t850 상위 BSS도 우리 +0.46 / +0.22 / +0.05입니다.
- 그러니 **"우리는 불확실성이 있고 NeuralGCM은 없다"는 6일 안에서는 장점이 아닙니다.** 오차가 4배 작은 결정론 예보는 0/1 확률로도 보정된 우리 앙상블보다 Brier가 좋습니다.
  보정된 산포가 이기는 상대는 ClimODE(22단계: 과소산포 σ, 72 h부터 BSS 음수)이고, NeuralGCM과의 확률 비교는 확률론 체크포인트(1.4°, 저자들은 CRPS로 보고)로 해야 공정합니다.
- 2020년 우리 확률 점수도 2017~18과 같습니다(SSR 1.24 / 1.14 / 1.11, 상위 BSS +0.62 / +0.31 / +0.08). 2020이 조금 더 좋은 것은 IC 구성 차이로 보입니다.

### 4.3 스펙트럼: NeuralGCM 평균이 종관 규모를 우리 평균보다 훨씬 잘 유지합니다

ERA5 대비 z500 동서 파워 비(파수 대역 1–4 / 5–9 / 10–20 / 21–32):

| | 72 h | 144 h |
| --- | --- | --- |
| NeuralGCM 2.8° | 0.97 / 0.95 / 0.83 / 0.74 | 0.98 / 0.83 / 0.79 / 0.71 |
| blend_band 멤버 | 1.03 / 1.17 / 1.87 / 7.96 | 1.07 / 1.64 / 5.16 / 19.75 |
| blend_band 평균 | 0.81 / 0.67 / 0.74 / 1.40 | 0.57 / 0.38 / 2.69 / 7.50 |
| regm_band 평균 | 0.78 / 0.59 / 0.46 / 1.89 | 0.55 / 0.41 / 0.67 / 3.15 |

- NeuralGCM 결정론은 144 h에도 종관 규모(5–9) 파워를 0.83 유지하고 우리 평균은 0.38로 뭉개집니다. NeuralGCM도 10 이상에서 0.7~0.8로 약간 매끄럽습니다(결정론 학습의 흔적).
- 우리 멤버의 작은 규모 과잉 파워(5~20배)는 22단계와 같은 약점입니다. 대역 Γ는 공간 규모를 보지 않습니다.

### 4.4 같은 정보의 초기장: 24 h 차이의 대부분은 초기장 정보이고, 3~6일은 절반쯤이 모델입니다

NeuralGCM에 우리 모델이 보는 것과 같은 정보만 줍니다(`--coarse-ic`): ERA5를 우리 64×32 격자로 보존 재격자하고 우리 12층만 남긴 뒤, log p 선형 보간으로 37층을 다시 만들고
(50 hPa 위는 등온 확장), 구름 얼음·액체 수분은 0으로, 그 장을 모델 격자로 쌍선형 보간합니다. 강제(SST·해빙)는 그대로입니다. 9개 IC(e = 5, 25, …, 165, 1월 11일부터 40일 간격)를
같은 IC의 원래 초기장 결과와 짝지어 봅니다(`scripts/step23_coarse_ic.py`, 그림 `docs/step23/fig_neuralgcm_coarse_ic.png`, 수치 `docs/step23/coarse_ic.json`,
`neuralgcm_coarse_paired.json`, `neuralgcm_sub9_paired.json`). 기각 규칙(H10): 거친 초기장에서도 NeuralGCM의 z500 24 h RMSE가 100 m²/s² 아래면 24 h 차이의 대부분은 모델입니다.

| 9개 IC, 2020 | z500 RMSE 24 / 72 / 144 h | t850 RMSE 24 / 72 / 144 h | z500 CRPS 24 / 72 / 144 h (m²/s²) |
| --- | --- | --- | --- |
| NeuralGCM, 원래 초기장 (0.25°, 37층) | 46 / 143 / 405 | 0.51 / 0.88 / 1.87 | 41 / 115 / 320 |
| NeuralGCM, 우리 초기장 (5.625°, 12층, 구름 수분 0) | 172 / 307 / 587 | 0.97 / 1.64 / 2.81 | 148 / 253 / 471 |
| blend_band (우리, 8멤버) | 201 / 472 / 742 | 1.61 / 2.51 / 3.24 | 141 / 317 / 476 |
| 지속성 | 584 / 900 / 1038 | 2.69 / 3.86 / 4.11 | 424 / 694 / 812 |

- **H10은 지지됩니다.** 우리 초기장에서 NeuralGCM의 z500 24 h RMSE는 172로 문턱 100을 크게 넘습니다. 짝 차이(우리 초기장 − 원래 초기장)는 z500 +125 [121, 130] / +164 [149, 180] / +183 [131, 233],
  t850 +0.46 / +0.77 / +0.93 K로 모든 lead에서 유의합니다. 9개 IC 모두 24 h가 160~186으로 고릅니다.
- **우리와의 차이를 나누면**(blend_band − 원래 초기장 NeuralGCM 가운데 초기장 정보 몫): z500 81 % / 50 % / 54 %(24 / 72 / 144 h), t850 42 % / 47 % / 69 %.
  24 h z500 차이 155 가운데 125가 초기장 정보, 29가 모델입니다. 72 h부터는 약 160 m²/s²가 모델 몫으로 남습니다.
- **같은 정보에서도 NeuralGCM이 RMSE로는 낫습니다.** blend_band − 우리 초기장 NeuralGCM: z500 +29 [17, 40] / +165 [140, 189] / +155 [96, 213], t850 +0.64 / +0.86 / +0.43 K.
  그러나 **확률 점수로는 24 h와 144 h에 같은 급입니다.** z500 CRPS 차이 −7 [−19, +5] / +64 [42, 95] / +6 [−44, +60] m²/s², t850 CRPS 144 h −0.2 [−0.4, 0.0] K(경계선에서 우리 쪽).
  결정론 하나를 8멤버 앙상블의 CRPS와 비교한 것이므로 이 "같은 급"은 앙상블의 몫입니다.
- 논문에 쓸 수 있는 문장: "같은 5.625°·12층 초기 정보에서 NeuralGCM 2.8°의 24 h z500 오차는 우리와 15 % 안쪽이고, CRPS는 24 h와 144 h에 우리 8멤버 앙상블과 구별되지 않는다.
  3~6일 RMSE 차이의 약 절반은 초기 정보, 나머지는 NeuralGCM의 역학 코어와 학습 물리다."

### 4.5 비용

같은 CPU 4코어에서 NeuralGCM 2.8°는 IC 하나에 약 15분(결정론 1멤버), 우리 2020년 생성 전체(FM 멤버, 회귀 멤버, G(x) 코어, 보정과 혼합)는 IC 180개 × 8멤버에 90분, 곧 IC당 약 30초입니다.
NeuralGCM은 TPU·GPU용이고 1 h 역학 시간 간격을 쓰므로 이 비교는 "같은 CPU에서"라는 조건에서만 의미가 있습니다. 학습 비용 비대칭은 2절의 표가 더 큽니다.

## 5. 약점

1. **표본이 작습니다.** 2020년 한 해, 18개 IC(20일 간격)이고 신뢰구간은 IC 부트스트랩입니다. 계절별 결론은 내지 않습니다.
2. **가장 약한 공개 체크포인트만 썼습니다.** 2.8° 결정론입니다. 1.4°·0.7° 결정론은 더 낫다고 보고되어 차이는 더 커질 것입니다. 확률론 1.4°를 돌리지 않았으므로 NeuralGCM과의 CRPS·Brier 비교는
   공정한 상대가 없습니다(GPU에서 `v1/stochastic_1_4_deg --members 8`).
3. **강제는 24 h 전 SST·해빙을 6일 동안 고정했습니다.** 저자 데모와 같고 6일 z500에는 영향이 작다고 보지만 NeuralGCM에 약간 불리한 쪽입니다.
4. **평가 격자가 우리 쪽입니다.** NeuralGCM 출력을 5.625°로 보존 재격자해 우리 ERA5와 비교합니다. 이 재격자는 NeuralGCM의 작은 규모 오차를 지워 RMSE에 약간 유리합니다. 정답장은 두 모델에 같습니다.
5. **같은 정보 실험의 "정보 몫"은 위쪽 한계입니다.** 우리 초기장은 NeuralGCM이 학습에서 본 적 없는 장입니다(보간한 37층, 구름 수분 0, 50 hPa 위 등온 확장, 쌍선형 보간).
   그래서 +125의 일부는 잃은 정보가 아니라 초기 충격(불균형)일 수 있고, 모델 몫 29는 아래쪽 한계입니다. 수평만 낮추기, 층만 줄이기, 구름 수분만 0으로 하기를 따로 돌리면 나뉩니다
   (각각 9개 IC × 15분). 9개 IC는 표본도 작습니다.
6. **불확실성 축에서도 집니다.** 4.2대로 결정론 NeuralGCM의 0/1 예보가 우리 확률 예보보다 Brier가 좋습니다. 논문에서 "NeuralGCM은 불확실성이 없다"를 장점 근거로 쓰면 안 됩니다.
   쓸 수 있는 것은 "같은 자료 규모의 ClimODE보다 보정이 좋다"와 "같은 CPU에서 IC당 비용이 약 30분의 1(멤버당 수백 분의 일)"입니다.
7. **회귀 앙상블 산포가 144 h에서 튑니다**(760 → 1040, SSR 1.26). 2017~18에도 같고(755 → 1034), 모든 IC에서 같아 회귀 기준선의 마지막 lead 특성입니다. blend_band는 FM 편차를 쓰므로 영향이 없습니다.
