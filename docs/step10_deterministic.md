# 10단계: 앙상블 평균을 결정론적 예측으로 보고, 보정 사다리로 operator의 몫을 검증

## 요청을 이렇게 읽었습니다

소유자 메모(2026-10-24)의 가설:

> 결정론적 기본 예측에 남은 오차에는 기후장 상태에 따라 달라지는 비국소적 공간 구조가 있고, neural operator는 이 구조를 학습해 단순 통계 보정이나 국소 보정보다 예측 오차를 줄일 수 있다.

모델 전체를 바꾸기 전에, 현재 최선 사슬(7단계 직렬 사슬: 고정 DCT encoder → latent flow matching → 멤버별 PINN Q → IDCT, Markov rollout 10일)의 **앙상블 평균**을 하나의 결정론적 예측으로 놓고 보정 사다리를 비교했습니다. 결정론적 backbone 재학습은 "operator가 MBM을 이길 때만" 진행하기로 했습니다.

    x̂_corr(t+k) = x̂(t+k) + N_φ(x̂(t+k), x_t, static, k)

각 lead를 직접 보정합니다(rollout에 되먹이지 않음). 소유자의 추가 요청(10:40, 10:42)대로 "멤버마다 MBM → CNN → operator → 마지막에 평균" 경로도 넣었습니다. 근거는 "operator는 함수를 받는데, 평균을 먼저 내면 학습 효과가 떨어질 것"입니다.

## 구현 (기존 구현 재사용)

| 부분 | 가져온 것 | 바꾼 것 |
| --- | --- | --- |
| operator | 소유자 파일 `ensemble_to_deterministic.py` → `pgcfm/ens_to_det.py` (공식 neuraloperator 2.0.0 `FNO`, 멤버 인코딩 → 평균 pooling → 전역 FNO, head 0 초기화) | **수정 없음.** 자체 test 통과. width 32, modes 8 |
| mean-only ablation | 같은 파일의 `mean_only` (같은 모델·용량, 편차만 제거) | 없음 |
| MBM | 9단계 `LinearMeanCalibrator` (lead·채널별 a + bμ, 최소제곱) | 없음 |
| 멤버별 MBM | 같은 클래스를 멤버 하나하나에 적용: x_m' = a + b x_m (멤버를 정답에 회귀, 풀링) | 없음 |
| 접공간 사영 | 9단계 `tangent_calibrated` | 결정론적 출력(M = 1)에 적용, 원래 평균에서의 전체 변화를 사영 |
| MBM + persistence 회귀 (`mbmx`) | 같은 최소제곱을 예측자 두 개로: a + bμ + c x_0 | 새로 씀(10줄). CNN·operator가 x_0을 context로 받으니 같은 정보를 쓰는 고전 대조군이 필요했습니다 |
| CNN | torch `Conv2d` 3×3 × 4층 (수용 영역 9칸), head 0 초기화 | operator와 같은 입력·context |
| 멤버 사슬 `MemberChain` | 위 CNN + 공식 `FNO` (`OfficialFNO` 어댑터) | 멤버마다 같은 CNN → FNO 잔차를 적용한 뒤 평균. 손실은 평균 출력(소유자 파일 방식) 또는 멤버별 MSE(`_mw`) |

context는 모든 학습 arm에서 같습니다: x_0(초기장), 지형, lead/10.

파일: `pgcfm/ens_to_det.py`, `scripts/run_step10_deterministic.py`, `tests/test_deterministic.py`, 원시 결과 `docs/step10_deterministic/results.json`.

## 실험 설정 (split 위생)

직렬 사슬은 2001–2004년으로 학습. 아래 기간은 모두 사슬이 본 적 없는 합성 연도이고, 초기장은 매일입니다(멤버 8, Heun 8 step, 10일).

| split | 기간 | 초기장 | 용도 |
| --- | --- | --- | --- |
| op_train | 2005 + 2007 | 160 | CNN / operator 학습 |
| cal | 2006 | 50 | **모든 고전 보정**(bias, MBM, mbmx, 멤버 MBM) 적합 |
| op_val | 2008 | 30 | CNN / operator checkpoint 선택(epoch별 검증 MSE) |
| test | 2021 | 50 | 한 번만 평가 |

MBM은 operator의 검증·시험 기간을 보지 않습니다. 점수는 정규화 단위, 면적 가중, TISR 제외 65채널. ACC는 op_train 정답의 기후값 기준 anomaly 상관입니다. "pattern"은 장마다 면적 평균을 뺀 RMSE, "grad"는 공간 차분장 RMSE, "band amp"는 DCT band별 예측 anomaly 파워 / 정답 anomaly 파워입니다(1이면 진폭 유지, 작으면 평활). 정역학 잔차(K)는 연속한 lead 사이의 전이에서 잽니다. 정답 자체의 잔차는 0.00 K입니다.

### 판정

**operator는 고전 보정을 이기지 못합니다. 그래서 결정론적 backbone 재학습으로 넘어가지 않았습니다.**

1. 평범한 MBM보다는 CNN·FNO가 모두 조금 낫습니다(1.176 → 1.154–1.158, 1.8%). 그런데 이득은 1–3일에만 있고(1일 1.132 → 1.05) 10일에는 없습니다.
2. 그 1–3일 이득의 출처는 공간 구조가 아니라 **context로 받은 초기장 x_0**입니다. persistence는 1일 RMSE가 0.740으로 앙상블 평균(1.176)보다 훨씬 좋습니다(7단계 W1, autoencoder 복원 바닥). 같은 x_0을 쓰는 고전 회귀 a + bμ + c x_0이 1.062로 모든 학습 arm보다 좋고, 1일에서 0.703입니다.
3. 그 고전 회귀 위에 CNN이나 FNO를 더하면 **나빠집니다**(1.062 → 1.085 / 1.107). 남은 오차에서 학습 가능한 부분을 찾지 못하고 과적합합니다.
4. 국소(CNN)와 전역(FNO)의 차이가 없습니다(1.156 vs 1.154). 가설이 기대한 "비국소 공간 관계의 추가 이점"이 보이지 않습니다.
5. 앙상블 pooling = mean-only = 멤버 사슬입니다(1.158 / 1.154 / 1.166). 아래 W3에서 이유를 봅니다.

## 취약점 (분석해야 할 것)

- **W1. 남은 오차에 예측 가능한 신호가 거의 없습니다.** MBM의 기울기 b가 1일 0.40에서 7일 이후 0.0 근처(10일 −0.08)로 떨어집니다. 5일 이후에는 앙상블 평균이 기후값보다 거의 나을 게 없다는 뜻이고(ACC 0.17), 최소제곱이 예측을 기후값으로 끌어내립니다. 오차 파워는 가장 큰 규모 band에 몰려 있지만(DCT band 파워 24 / 5.1 / 1.5 / 0.14), 그 큰 규모 오차가 입력으로부터 예측되지 않습니다. 초기장 회귀의 계수를 보면 더 분명합니다. 채널 평균으로 x_0의 계수 c는 0.79(1일) → 0.40(4일) → 0.09(10일)이고, 앙상블 평균의 계수 b는 −0.12–0.06으로 거의 0입니다. x_0이 있으면 최소제곱이 사슬의 예보를 거의 쓰지 않는다는 뜻입니다. 이것은 "공간 구조가 없다"가 아니라 "조건부 평균이 거의 0"이라는 뜻입니다. 소유자 메모의 "기본 모델이 정보를 이미 다 썼다면 개선 여지가 작다"와 같은 상황입니다.
- **W2. 보정된 입력 위의 학습 arm은 모두 첫 epoch에서 최고이고 이후 과적합합니다.** 예를 들어 MBM + FNO mean-only는 학습 MSE가 1.18 → 0.65로 내려가는데 검증 MSE는 1.28 → 1.47로 올라갑니다. MBM 없이 원래 평균에 붙인 FNO만 7 epoch째가 최고였는데, 선형 보정부터 배워야 했기 때문으로 보입니다. 학습 초기장 160개 × lead 10개입니다. 결과가 "operator가 쓸모없다"인지 "자료가 너무 적다"인지는 이 규모로 구분할 수 없습니다. ERA5에서는 초기장 수가 수십 배라 이 부분은 다시 봐야 합니다.
- **W3. 이 사슬에서는 "평균 전에 함수를 보존"해도 얻을 정보가 거의 없습니다.** 원래 앙상블의 퍼짐은 0.31(1일)–0.60(10일)이고 SSR은 0.28–0.51입니다(과소분산). 멤버별 MBM은 b가 작아서 퍼짐을 0.13 / 0.06으로 더 줄이고, 멤버 사슬은 그 뒤에 0.12 / 0.06(멤버별 MSE는 0.10 / 0.05)으로 유지합니다. 멤버가 평균 근처에 몰려 있으면 mean(φ(x_m)) − φ(mean x_m)은 퍼짐의 2차 크기라서, 소유자의 가설(평균을 먼저 내면 함수 정보가 사라진다)은 맞는 말이지만 이 앙상블에서는 효과가 측정되지 않을 만큼 작습니다. 이 가설을 제대로 검증하려면 퍼짐이 보정된(SSR ≈ 1) 앙상블, 예를 들어 8단계 `tangent_inflate`나 9단계 MBM + s_kc 출력을 입력으로 써야 합니다. 또 멤버별 MBM은 퍼짐을 b배로 줄이므로, 원래 MBM(Van Schaeybroeck & Vannitsem 2015)처럼 편차 배율을 따로 두어야 합니다.
- **W4. 평균을 고치는 모든 보정이 정역학 균형을 깹니다.** MBM은 Φ와 T에 다른 a, b를 쓰므로 10일 잔차가 1.0 → 6.5 K, MBM + persistence 회귀는 7.6 K입니다. 9단계와 같은 결과이고, 접공간 사영으로 RMSE 손실 없이 원래 수준(1.0–1.3 K)으로 돌아옵니다. 결정론적 경로에서도 사영은 공짜이니 기본으로 둬야 합니다.
- **W5. 결정론적 보정은 진폭을 지웁니다.** 앙상블 평균의 anomaly 파워는 정답의 20–25%, MBM 뒤에는 5%입니다. RMSE와 ACC는 좋아지지만 장은 기후값에 가까운 매끈한 장이 됩니다. 결정론적 모델로 갈 때 RMSE만 보면 이 평활을 "개선"으로 고르게 됩니다. band 진폭이나 스펙트럼을 같이 보고해야 합니다.
- **W6. 격자별 bias는 과적합합니다.** 보정 초기장 50개로 격자점마다 bias를 맞추면 1.228 → 1.273으로 나빠집니다. 국소 통계 보정에는 수축(shrinkage)이나 더 긴 보정 기간이 필요합니다.
- **W7. 소유자 파일의 FNO는 위도 방향도 주기 경계입니다.** 직사각형 격자 위치 encoding이라 남극과 북극이 이어집니다. 파일 주석이 이미 경고하는 부분이고, 이번 결론(operator가 이득이 없음)을 바꾸지는 않지만 ERA5에서는 9단계의 SFNO나 위도 padding을 써야 합니다.

## 다음 단계 제안

1. 결정론적 backbone 재학습은 **보류**합니다. 진입 조건(operator > MBM 계열)을 통과하지 못했습니다.
2. 결정론적 오차의 가장 큰 몫은 1–3일에 persistence보다 나쁜 것이고, 원인은 7단계 W1(autoencoder 복원 바닥)입니다. post-hoc operator보다 backbone 쪽(예: carry_highpass, 잔차 학습)에서 고칠 문제입니다.
3. ERA5에서는 같은 사다리를 `mbmx`(MBM + persistence 회귀)와 접공간 사영을 포함해 다시 돌리고, 초기장 수가 늘어날 때 W2(과적합)가 풀리는지 봅니다.
4. 소유자의 "평균 전 함수 보존" 가설은 SSR ≈ 1로 보정된 앙상블을 입력으로 다시 검증합니다(W3).

    python scripts/run_step7_latent.py --out runs/step7 --arms lat_serial    # 직렬 사슬 (CPU 약 45분)
    python scripts/run_step10_deterministic.py --out runs/step10_det --step7 runs/step7
    python scripts/run_step10_deterministic.py --out runs/step10_det --step7 runs/step7 --epochs 8 \
        --arms mbmx member_mbm mbmx_cnn mbmx_fno_ens member_chain member_chain_mw

첫 번째 step10 실행은 25 epoch, 두 번째는 8 epoch입니다(이 arm들이 모두 첫 epoch에서 최고라 결과에 거의 영향이 없습니다). CPU 4코어에서 rollout 약 1분, 학습 arm마다 5–12분 걸립니다.
