# 18단계: 물리·flow matching 앞단의 downscaling — 해상도 상한 시험

소유자(2026-10-27 23:31, arXiv 2403.17847 첨부): "climate downscaling인데 이걸 물리랑 앞으로의 flow matching 전에 적용하도록 해보는건 어떨까요?"

## 요청을 이렇게 읽었습니다

제안은 5.625° 상태를 먼저 더 고운 격자로 복원(super-resolution, SR)한 뒤 그 위에서 물리 연산자와 멤버 생성을 돌리자는 것입니다. 16·17단계의 결론이 "5.625°·12층의 이산 연산자는 실제 경향을 거의 못 본다(닫힘 결손 + 절단오차)"였으므로, 수평 절단오차가 병목이라면 SR이 그 병목을 풀 수 있습니다. 그러나 SR은 **수평 세부만** 더합니다. 연직 12층, ω(연직속도) 부재, 비단열 닫힘은 그대로입니다. 그래서 먼저 "수평 해상도가 실제로 상한인가", 그리고 "그 상한을 푸는 데 **실제 고해상도 정보**가 필요한가, 아니면 보간(새 정보 없음)으로 충분한가"를 자료로 재야 합니다. SR 모델의 출력은 어떤 경우에도 보간과 실제 자료 사이에 놓이므로, 이 둘을 재면 SR이 줄 수 있는 이득의 **상한**이 나옵니다.

## 1. 첨부 논문 요약 (Chiang et al. 2024, arXiv 2403.17847)

- 과제: 대만 일강수의 통계적 downscaling. 입력 ERA5 0.25°, 목표 TCCIP 5 km 관측 격자. 단일 변수, 지역 한정, 결정론적(MSE) 지도학습.
- 구조: 앞단 cascaded conv "bias correction" → CBAM(채널·공간 주의) residual attention block들 → skip connection(shrinkage + fusion) → pixel-shuffle(ESPCN) 한 번 업스케일. 지형(고도)을 입력에 결합.
- 지표: MAE/RMSE/상관/SSIM, 강수 유무 POD/FAR/TS. 비교 대상은 bicubic·SRCNN 계열.
- 우리 문제에 옮길 때의 간극: (i) 단일 변수 강수 → 66채널 역학 변수, (ii) 결정론적 SR = 조건부 평균(매끈함; 앙상블 퍼짐과 무관), (iii) 관측 격자로의 downscaling → 우리는 더 고운 **재분석** 격자가 목표이고 시험 연도의 고해상도 진실이 필요, (iv) 채점은 ClimODE 규약대로 5.625°에서 하므로 고해상도 출력은 다시 거칠게 평균해야 함.

파이프라인 안의 자리(소유자 제안대로 **앞단**): x(5.625°) → SR → x(2.8°) → [물리 연산자 / 코어 / 멤버 생성] → 2.8° 멤버 → 5.625°로 평균 → 채점. 뒷단(멤버마다 SR)은 채점 격자가 5.625°인 한 점수를 바꾸지 못합니다.

## 2. 상한 시험 설계 (기존 구현 재사용)

- 자료: WeatherBench2 2.8125° (128×64, 보존 재격자) 2016년을 `scripts/wb2_to_kai.py --grid 128x64 --days-step 8 --all-hours`로 KAI 67채널 배치에 변환(8일마다 하루 4회, 46일 × 4 = 184 상태, 287 MB). 같은 날짜의 5.625° 상태는 기존 `kai6h/2016.nc`에서 꺼냄.
- 세 원천, 같은 92개 (x_{t-6}, x_t, x_{t+6}) 삼중항:
  - **coarse** 5.625° 원자료(32×64), 11~17단계의 격자.
  - **fine** 2.8° 실제 자료(64×128).
  - **interp** 5.625° 상태를 2.8° 격자로 보간: 경도는 FFT 영채움(대역 제한 보간, 원 격자점은 그대로), 위도는 3차 스플라인(끝 행 ±88.6°는 외삽), 지형은 fine 파일의 실제 지형(downscaler가 지형을 안다는 설정). 선형이라 z-score와 교환 가능.
- 물리: 16단계의 강형 잔차(`StrongPhysics`, `pgcfm/physics`)를 격자별 위도 등록으로 두 격자에 그대로 적용. 중심차분 경향 ẋ = (x_{t+6} − x_{t-6})/2 에 대해 R1 = ẋ + A_h(x)(전체 잔차), R0 = A_h(x)(정지 상태 잔차 = −이산 연산자의 자체 경향), D = R1 − R0 = ẋ(경향항). 위도 면적 가중, 지하 격자점·85° 극관 제외.
- 지표(예보 방정식 u, v, T, q마다): corr(−R0, D) = **이산 연산자가 실제 경향을 맞히는 상관**; skill = 1 − ⟨R1²⟩/⟨D²⟩(연산자 경향을 그대로 예측자로 쓸 때, 1 = 정확, 0 = 무용); 16단계의 동서 파수별 비 |D_k|²/|R1_k|²(1 위에서 연산자가 그 규모의 접선을 봄). 보간 간극(interp와 fine의 상대 RMSE, fine의 k>32 파워 비율)도 기록.
- 판독 규칙: fine ≫ interp → 고해상도 자료에 보간이 못 주는 정보가 있고 SR은 그것을 **자료에서 배워야** 이득; fine ≈ interp → 이득은 더 고운 스텐실(보간으로 공짜) ; 둘 다 ≈ coarse → 수평 해상도는 병목이 아님.

실행: `python scripts/step18_resolution_test.py --coarse /home/claude/era5/kai6h --fine /home/claude/era5_hres/kai6h --stats runs/step16/stats --out docs/step18 --threads 2` (약 2분). 결과 `docs/step18/resolution_test.json`, 그림 `docs/step18/fig_resolution_test.png`.

## 3. 결과 (2016, 92 상태)

보간 간극(interp vs fine 상대 RMSE / fine 파워 중 k>32 비율): z 0.03/0.001, t 0.06/0.003, u 0.19/0.005, v 0.19/0.009, q 0.20/0.03. 2.8° 자료가 5.625° 보간과 다른 부분은 바람·습도의 약 20 %이고, 그 차이는 k>32의 동서 세부(1 % 미만)가 아니라 **보존 재격자(상자 평균)로 지워진 위도·진폭 구조**에 있습니다.

| 원천 | corr(−R0, D) u | v | T | q | skill u / v / T | ‖R0‖/‖D‖ u / v / T | 누적 비 k≤8 u / v / T |
|---|---|---|---|---|---|---|---|
| coarse 5.625° | 0.52 | 0.50 | 0.35 | 0.32 | −1.9 / −3.1 / −5.2 | 2.0 / 2.3 / 2.7 | 0.65 / 0.16 / 0.28 |
| interp 5.625°→2.8° | **0.56** | **0.63** | **0.42** | 0.38 | −1.4 / −1.0 / −3.4 | 1.9 / 1.8 / 2.3 | 0.82 / 0.45 / 0.44 |
| fine 2.8° 실제 | **0.56** | 0.60 | 0.35 | **0.39** | −1.6 / −1.5 / −5.7 | 2.0 / 2.0 / 2.8 | **1.07 / 0.55 / 0.48** |

진단식 잔차 RMS: mass coarse 2.8e-6, interp 2.9e-6, fine 4.8e-6 (보존 재격자는 비발산을 보존하지 않음); hyd 세 원천 모두 3.0.

### 판독

1. **실제 2.8° 자료는 보간보다 연산자를 더 맞히지 않습니다.** u 0.56 = 0.56, v 0.60 < 0.63, T 0.35 < 0.42, q 0.39 ≈ 0.38. 더 고운 격자가 주는 이득(v 0.50→0.63, T 0.35→0.42)은 **스텐실의 절단오차 감소**이고, 이는 보간으로 공짜로 얻습니다. 실제 자료는 거기에 연산자가 설명 못 하는 작은 규모의 경향(‖D‖ +16 %)을 더해서 T는 coarse 수준으로 되돌아갑니다. SR 모델의 출력은 interp와 fine 사이이므로, **완벽한 SR이라도 연산자 상관은 보간보다 좋아질 수 없습니다.**
2. **큰 규모(k≤8)의 파워 비는 실제 자료에서 더 높습니다**(u 0.82→1.07, v 0.45→0.55). 5.625°의 상자 평균이 지운 진폭·위도 구조가 큰 규모의 균형에는 보입니다. 즉 "새 정보"는 있으나, 모든 규모를 합친 상관에서는 작은 규모의 손해에 상쇄됩니다. 이것이 SR이 줄 수 있는 이득의 상한이고, 그 이득은 u/v의 큰 규모에만 있습니다.
3. **T는 세 격자 모두 0.35~0.42, skill −3 ~ −6.** 온도 방정식의 병목은 수평 해상도가 아니라 닫힘(비단열 가열, ω, 12층)입니다. 16단계에서 본 "T 경향 비 0.27"은 downscaling으로 풀리지 않습니다.
4. **skill은 모든 격자·방정식에서 음수**: 이산 연산자의 자체 경향은 실제 경향보다 2~2.8배 큽니다(‖R0‖/‖D‖). 상관 0.5~0.6은 "방향은 반쯤 맞고 크기는 2배 틀린" 연산자입니다. ERA5에서 "정확한 연산자 + 학습 닫힘항" 하이브리드(17단계의 hybrid arm)를 만들면 닫힘항이 연산자 경향의 절반 이상을 **되돌려야** 하므로, 구조가 주는 사전지식은 크지 않습니다. 이것이 ERA5 하이브리드를 적분 형태로 만들지 않는 정량적 근거입니다(그 외의 이유: 300 m/s 중력파의 CFL로 6 h에 24 부단계, Φ·sp에 예보식이 없어 닫힌 계가 아님).

### 결정

- **SR을 ERA5 앞단에 두는 실험은 하지 않습니다.** 상한 시험에서 이득이 보간으로 대체되고, T의 병목은 수평이 아니며, 2.8°에서의 sequence FM/멤버 생성은 CPU 밖(5.625°에서 시험 연도당 55분 → 4배 격자면 학습·표본 모두 4배 이상)이고, 채점은 5.625°라서 결과를 다시 평균해야 합니다.
- 공짜로 얻을 수 있는 것은 **연산자를 보간된 2.8° 격자에서 계산하는 것**(v 상관 +0.13, T +0.07)인데, 현재 보고 모델(13단계 regm_sband_clim_flow)은 물리 연산자를 멤버 경로에 쓰지 않으므로(hyd 투영은 연직 폐형식, 격자 무관) 점수에는 닿지 않습니다. 물리 연산자를 다시 멤버 경로에 넣는 날(예: G(x) 특징 arm) 2.8° 스텐실을 쓰면 됩니다.
- 남는 ERA5 쪽 "물리를 구조로" 시험은 **G(x) = −R0(x)를 코어의 입력 특징으로 주는 arm**뿐입니다: 상관 0.5의 경향 추정을 네트워크가 맞는 곳에서만 쓰게 하는 설계로, 적분 형태의 CFL·닫힘 문제가 없습니다. 17단계 SWE hybrid arm(정확한 연산자 + 학습 닫힘항)이 끝나면 그 결과와 함께 판단합니다.

## 4. 약점

1. 2016년 46일(8일 간격) × 4회만 썼고 1년치입니다. 계절 편향은 없으나 92 상태의 표본 오차가 상관 둘째 자리에 들어갈 수 있습니다(8 상태 시험과 92 상태의 차이는 u ±0.03, T ±0.06).
2. "실제 2.8°"는 WB2의 보존 재격자(0.25° 상자 평균)이지 2.8° 모델의 자체 상태가 아닙니다. 상자 평균은 비발산을 깨고(mass 잔차 1.7배) 작은 규모를 매끈하게 하므로, 진짜 고해상도 역학의 상한보다 보수적일 수 있습니다.
3. 보간 통제는 FFT + 3차 스플라인 하나뿐입니다. 다른 보간(보존 역재격자, 구면조화 절단)은 시험하지 않았습니다.
4. 강형 잔차는 12층·ω 없는 연산자라 T·q의 상한이 닫힘에 가려 있습니다. 수평 해상도의 효과를 T에서 분리하려면 ω가 있는 연산자가 필요합니다(WB2 2.8° 파일에는 `vertical_velocity`가 있어 다음 시험에 쓸 수 있음).
5. SR 모델 자체는 만들지 않았습니다. 이 단계는 상한만 쟀고, "fine ≈ interp"가 보간의 손을 들어 주어 모델 구축을 생략했습니다. 큰 규모(k≤8)의 실제 정보가 멤버 생성에 중요하다고 보면, 2.8° 자료 4년(약 2.4 GB)로 논문 구조의 축소판을 학습시키는 것이 다음 실험입니다.
