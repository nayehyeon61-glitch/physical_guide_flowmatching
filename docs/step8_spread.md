# 8단계: 앙상블 분포 보정 (과소분산, H1/H2)

## 요청을 이렇게 읽었습니다

7단계 직렬 구조(DCT encoder → latent CFM 멤버 → 멤버별 PINN Q → decoder/IDCT)를 고정하고, Neural Operator의 역할을 "멤버를 고치는 것"에서 "앙상블 분포(퍼짐, 공분산, 시간 진화)를 다루는 것"으로 바꿉니다(H1). 그리고 PINN이 물리적으로 가능한 다양성까지 수축시키는지(H2) 확인합니다. 순서는 소유자 제안대로 A(학습 없는 spread scaling) → DCT band별 보정 → PINN 제거·정역학 사영 → C(접공간 잡음) → B(공분산 operator)입니다. ERA5 직렬 단독(순서 1)은 GPU가 필요하므로 이 문서의 끝에 명령어로 남깁니다.

## 구현 (기존 구현 재사용)

| 부분 | 가져온 것 | 바꾼 것 |
| --- | --- | --- |
| spread scaling | EnKF 곱셈 inflation(DAPPER 등의 `E = mu + infl (E - mu)`) | rollout 안에서 매 스텝 적용(보정된 멤버가 다음 초기장), 평균 유지 |
| DCT band | torch-dct(7단계와 같은 DCT-II) | 유지한 k_lat×k_lon 블록을 반경으로 3 band, band마다 α_b |
| 정역학 사영 | `coupling.HydrostaticProjection`(4단계) | Q 대신 CFM 출력에 T ← Φ |
| 접공간 사영 P_T | `torch.func.vjp` + 3단계 정역학 잔차 | 잔차가 (Φ, T, q)에 선형(상대 변화 7e-5)이고 격자 기둥마다 국소라서, 층마다 vjp 한 번으로 J를 정확히 만들고 P_T = I − Jᵀ(JJᵀ)⁻¹J. jvp와 비교한 상대 오차 2.5e-8 |
| 공분산 operator (B) | neuraloperator `FNO` + `SpectralConv` | FNO가 (평균, log spread, 조건) → 유계 log-scale 장, 선형 SpectralConv(bias 없음)가 편차 장을 섞음. 편차에 선형이라 Σ → AΣAᵀ이고 평균은 움직이지 않음. 학습은 7단계 `train_operator`(fair energy score, 1→2→3일 curriculum, 상한 있는 물리 항) |

접공간은 진단 제약(정역학)만으로 정의했습니다. 예보 방정식(운동량, 열역학)의 잔차는 x_k가 주어지면 tendency 자체를 정하므로, 그 null space에 사영하면 앙상블이 담아야 할 동역학적 불확실성까지 거의 다 지워집니다.

파일: `pgcfm/spread.py`, `scripts/run_step8_spread.py`(이 문서의 실험, 원시 결과 `docs/step8/results.json`), `scripts/fit_spread.py`(ERA5 검증 기간에서 보정 적합), `scripts/infer_pgcfm.py --spread`, `tests/test_spread.py`.

| 이름 | 멤버 (μ, δ = 멤버 평균과 편차, pre = Q 전 D(z_cfm), post = Q 후) |
| --- | --- |
| serial | post (7단계 그대로) |
| inflate (A) | μ_post + α δ_post |
| tangent_inflate (C + A) | μ_post + α P_T δ_post + (I − P_T) δ_post: 허용 방향만 키움 |
| band (4) | μ_post + Σ_b α_b P_b δ_post |
| posthoc (A, 되먹임 없음) | rollout이 끝난 뒤 lead마다 α_k |
| noQ (3) | pre: 추론에서 Q를 뺌 |
| noQ_hyd (3) | pre에 정역학 hard 사영 |
| qmean | μ_post + δ_pre: Q는 평균만 고침 |
| tangent (C) | μ_post + P_T δ_pre: CFM 다양성을 접공간에서 유지 |
| covop / covop_nophys (B) | serial → 공분산 operator (± 물리 항) |
| covop_tangent (B in C) | tangent → 공분산 operator → 편차를 다시 P_T로 |

## 실험 설정

7단계와 같은 합성 자료, 같은 b_j, 같은 고정 모델(`runs/step7/serial.pt`). 자유 파라미터(α, α_b, α_k, operator)는 모두 **보정 기간**(2005년, 기본 사슬이 본 적 없음)의 10일 rollout 16개로만 맞춥니다. 점수는 두 시험 세트에서 냅니다: 7단계 시험(2020년, 초기장 4개, 7단계 표와 비교용)과 새 독립 시험 **test16**(2021년, 초기장 16개). 멤버 8, Heun 8 step, Markov rollout(보정된 멤버를 되먹임).

- inflate: α ∈ {1, 1.15, …, 5}에서 보정 기간 평균 CRPS 최소 → α = 2.0.
- band: α에서 시작해 band마다 ×{0.6, 0.8, 1.25, 1.6} 좌표 탐색 → [2.0, 2.5, 2.0].
- posthoc: lead마다 1.0–6.0 → α_k = 4.6, 3.6, 3.2, 2.9, 2.7, 2.6, 2.5, 2.4, 2.3, 2.3.
- covop: 150 iter, 멤버 4, 보정 기간 3일까지의 curriculum, BPTT 없음(스텝마다 기울기), λ_P = 0.1(상한 0.5).

### H2: Q가 다양성을 수축시키는가

| 측정 | 결과 |
| --- | --- |
| 한 스텝, 같은 초기장(멤버가 같은 x_k) | Q 뒤 분산 = Q 전의 **1.57배**. 접공간 성분 1.57배, 법선 성분 0.91배. 법선 성분은 분산의 0.06% |

| 물리 없이 학습한 직렬(`serial_nophys`), rollout lead 1 / 3 / 6 | Q 뒤 분산 = Q 전의 **1.36 / 1.16 / 1.08배**(늘림). 법선 성분 비율 0.04% / 0.03% / 0.02% |
| 물리 없음, 한 스텝 같은 초기장 | 2.83배 |
| 물리 없음, test16 점수 | CRPS 0.718 / 0.696 / 0.682(평균 0.701), SSR 0.40 / 0.60 / 0.66, hyd 1.62 / 2.69 |

같은 구조·같은 seed에서 물리 항만 다릅니다. 물리 항이 있으면 Q가 rollout에서 분산을 줄이고, 없으면 늘립니다. 두 경우 모두 편차는 99.96% 이상 접공간에 있으므로, **물리 항이 Q로 하여금 허용 방향의 분산을 지우게 만든다**는 것이 이 실험의 결론입니다(H2의 강한 형태). 물리 없는 직렬은 퍼짐은 크지만 평균이 나빠 test16 평균 CRPS는 0.701로 serial(0.689)보다 나쁩니다. 그래서 물리 항을 빼는 대신 평균은 Q로, 편차는 접공간에서 보존하는 쪽(tangent, tangent_inflate)이 둘 다를 얻습니다.

## 가설별 판정

- **A (spread scaling): 성공.** α = 2 하나로 test16 평균 CRPS가 0.689 → 0.572(−17%), 10일 coverage가 0.52 → 0.85. 복잡한 operator 없이도 분산 보정이 대부분의 이득을 냅니다. 대가는 두 가지입니다. rollout 안에서 α가 누적되어 5일 이후 SSR이 1.3으로 넘치고(1일은 0.59로 여전히 부족), 정역학 잔차가 2.10 → 3.98로 두 배가 됩니다(편차의 법선 성분도 함께 키우기 때문).
- **C + A (허용 방향만 키우기): 같은 점수, 물리는 더 좋음.** tangent_inflate는 inflate와 CRPS가 같고(0.572), 정역학 잔차는 1.74로 serial(2.10)보다도 낮습니다. "물리 제약을 만족시키려고 분포를 수축시키지 말고, 허용 방향의 불확실성을 보존한다"는 중심 가설을 이 실험에서는 지지합니다.
- **H2: 시간 방향으로 맞고, 원인은 물리 항입니다.** 같은 초기장에서 한 스텝만 보면 Q는 퍼짐을 오히려 키웁니다(1.57배). 하지만 rollout에서 멤버가 서로 다른 x_k에서 출발하면 Q가 스텝마다 분산의 15–24%를 지우고, 지우는 분산은 거의 전부 접공간(허용 방향)입니다(법선 성분은 0.03–0.04%). 물리 항 없이 학습한 Q는 같은 측정에서 분산을 8–36% 늘립니다. 그래서 Q가 평균만 고치게 하면(qmean, tangent) 5–10일이 좋아집니다. 반대로 Q를 아예 빼면(noQ) 평균이 나빠져 모든 lead에서 집니다. **Q는 평균에는 필요하고, 멤버 편차에는 해롭습니다.**
- **tangent (적합 파라미터 0개).** μ_post + P_T δ_pre는 학습도 α도 없이 10일 CRPS 0.649 → 0.582, 정역학 잔차 2.10 → 0.72. 같은 편차를 사영 없이 쓰면(qmean) 0.594 / 2.69이므로, P_T가 한 스텝 분산의 0.06%만 건드리는데도 rollout에서는 정역학 불균형의 누적을 막아 점수와 물리를 함께 개선합니다.
- **정역학 hard 사영만으로는 점수가 오르지 않습니다.** noQ_hyd는 잔차를 0으로 만들지만 CRPS는 noQ와 같거나 나쁩니다. 물리 제약을 지키는 것과 확률 보정은 별개의 문제라는 소유자 해석과 맞습니다.
- **4 (DCT band): 부족한 정도는 band마다 다르지만, CRPS로 맞춘 band α는 스칼라와 같습니다.** serial의 spread/error power 비는 10일에 대규모 0.28, 중간 0.31, 소규모 0.54(가장 큰 규모가 가장 부족). band α는 [2.0, 2.5, 2.0]로 평균 CRPS 0.571(스칼라 0.572)입니다. CRPS가 격자점별 점수라 band 사이의 차이를 거의 보지 못합니다(W3).
- **B (공분산 operator): 짧은 lead는 가장 좋지만 학습 horizon 밖에서 과대분산.** covop은 되먹임 보정 중 1일이 가장 좋고(0.604), 평균을 움직일 수 없어서 7단계 operator와 달리 발산하지 않습니다(10일 진폭 1.71, v1은 59–386). 하지만 3일까지만 학습해서 5일 이후 SSR 1.7로 넘칩니다. 물리 항을 빼면 과대분산이 SSR 2.9, 정역학 잔차 11.5로 커지므로, 이 구조에서는 물리 항이 inflation의 정규화 역할을 합니다. 접공간 안에 가두면(covop_tangent) 같은 CRPS(0.592)에 정역학 잔차 0.85–0.93로, 학습된 보정 중 물리가 가장 좋습니다.

## 취약점 (분석해야 할 것)

- **W1. AE 바닥은 그대로입니다.** 모든 보정은 멤버 분포만 바꾸고 평균은 직렬 사슬 그대로라, 1일 CRPS(0.58–0.75)는 grid CFM(0.485)에 집니다. 절단 모드 밖(4번째 band)에는 멤버 power가 0이라 그 오차는 어떤 보정으로도 퍼짐으로 덮을 수 없습니다. 실제 ERA5에서 encoder 바닥이 먼저입니다(소유자 지적과 같음).
- **W2. 상수 α는 lead에 따라 넘치고 모자랍니다.** 1일 SSR 0.59, 5일 이후 1.3. posthoc의 α_k(4.6 → 2.3)가 보여주듯 필요한 배율은 lead에 따라 줄어듭니다. 되먹임 안에서 lead별(또는 상태 의존) α가 필요하고, 이것이 operator의 실제 역할로 보입니다. 지금 covop은 3일까지만 학습해서 이 감소를 배우지 못했습니다.
- **W3. 점수가 공간 구조를 보지 못합니다.** CRPS와 fair energy score 모두 band별 결손(대규모 0.28 vs 소규모 0.54)을 거의 구분하지 못합니다. 5단계 평가 모음의 spectrum 진단, 또는 band별 spread-error 비를 손실로 쓰는 실험이 필요합니다.
- **W4. 접공간은 정역학 하나뿐입니다.** 편차의 법선 성분이 원래 0.06%라 한 스텝 효과는 작고, 이득은 rollout 누적에서 나옵니다. 운동량·질량 보존(지균 균형 등)의 진단 제약을 접공간에 넣으면 결과가 달라질 수 있습니다. J는 각 앙상블의 첫 멤버 x_k에서 계산합니다(선형성 7e-5라 근사 오차는 작음).
- **W5. 자료가 작습니다.** 보정 기간 1년 16 rollout, 시험 16 + 4 초기장, 멤버 8. 두 시험 세트의 순위는 같지만 차이 0.01 이하는 잡음 수준입니다(inflate vs tangent_inflate vs band).
- **W6. 수축의 기제는 아직 간접 증거입니다.** 물리 항 유무로 수축 방향이 바뀌는 것은 확인했지만, 왜 접공간 분산을 지우는지(물리 잔차가 x_k와 멤버 사이의 tendency 방정식이라 x_k가 다른 멤버를 같은 tendency 쪽으로 끌어당기는 것인지)는 운동량·열역학 잔차별로 나눠 봐야 합니다. Q 학습의 CRPS가 멤버 2개로 계산되어 평균 쪽으로 기운 효과도 섞여 있을 수 있습니다.
